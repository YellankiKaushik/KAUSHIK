# Design specification

Use warm paper, near-black ink, and a burnt orange accent. The KY monogram is the persistent identity. Build around display typography, short supporting text, ruled layouts, and a portrait from the repository. Let project illustrations and the process section carry visual detail.

Navigation goes directly to work, about, writing, and contact. Place source and demo links beside the relevant case study. Use a native disclosure for the mobile menu and for supplementary credentials. Preserve native scrolling on touch and reduced-motion configurations.

Use accessible contrast, explicit keyboard focus, section anchors with clearance from the sticky header, and a single main landmark per route. Keep layouts usable down to narrow mobile widths. Style editorial and project routes with the same shell.
